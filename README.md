# Dashboard de Vendas — Porsche Brasil

Dashboard interativa em arquivo único (HTML), que responde a três perguntas
de negócio sobre 100 vendas da Porsche. Publicada no GitHub Pages.

**Acesse a dashboard:** [cole aqui o link do formato
https://davidmmss-wq.github.io/dashboard-vendas-porsche — ele só existe
depois de ativar as Páginas]

## Perguntas de negócio escolhidas

1. **Qual modelo gera mais receita?** — responde com gráfico de barras por
   modelo; orienta estoque e foco de marketing.
2. **Onde estão concentradas as vendas?** — responde com gráfico por estado;
   orienta expansão regional.
3. **O preço médio sobe com o ano do veículo?** — responde com linha por ano
   (2019 a 2024); mostra a demanda por modelos novos vs. usados.

## Tratamento da base antes da IA

- Mantive apenas as colunas sanitizadas da planilha;
- Converti preço e ano para número;
- Colei os dados como valores, sem fórmulas quebradas;
- Os dados ficam embutidos no próprio HTML e não contêm informações sensíveis.
